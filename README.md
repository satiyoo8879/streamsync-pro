<h3 align="center"> Dual-Stream Live Chat Aggregator & Auto-Clipper </h3>

<p align="center">
  Aplikasi desktop super ringan bergaya <b>Glassmorphism UI</b> yang dirancang khusus untuk streamer yang melakukan <i>live</i> secara bersamaan di <b>TikTok</b> dan <b>YouTube</b>.
</p>

---

##  Fitur
*  **Hybrid Chat Engine:** Membaca 100% aliran komentar dari dua platform secara real-time tanpa delay.
*  **Radar Pertanyaan:** Filter otomatis kalimat tanya dari penonton agar tidak tertelan spam.
*  **Smart IDR Gift Converter:** Gabungkan Koin TikTok & SuperChat YouTube menjadi estimasi Rupiah.
*  **Auto-Clipper System:** Deteksi otomatis saat komentar meledak/hype dan catat waktu VOD-nya!
*  **Mobile Companion:** Scan QR Code untuk menjadikan HP Anda sebagai layar kedua.
*  **Smart TTS:** Robot pembaca komentar yang pintar mendeteksi kata spam dan simbol.
